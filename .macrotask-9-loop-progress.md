## Phase 2 implementation notes

- `EventSlotProposal` gained `verified_no_change: bool = False`.
- `_triage_one_event` now returns `(applied, missing_context, verified_no_change)`.
- `_honest_verified_no_change`: True only when the flag is set **and** `slots` is empty **and** `applied == 0`. Non-empty missed slots cannot confirm.
- `_record_verdict` branches:
  1. `applied >= 1` → `confirmed` (no pending MERGE).
  2. `applied == 0` and `verified_no_change` → `confirmed` (no pending MERGE, does not consume a listen-window check).
  3. else → MERGE `:PendingEventContext` / increment `checks_without_progress` → `waiting` or `incomplete` as today.
- `SYSTEM_PROMPT` tells the model to set the flag only when the graph is already correct and the slot list is empty; “non so” stays `verified_no_change=False`. No search-tool instructions.
- Exception path in `run_event_triage` still records with `verified_no_change=False`.
