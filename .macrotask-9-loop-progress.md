## Phase 3 implementation notes

### Reconnaissance finding

`get_metadata` does **not** expose `:Chunk.text`. Evidence:

- `NodeMetadataResponse` (`schemas.py`) has `summary` (and name/attributes/identity_uris) — **no chunk-text field**.
- `get_node_metadata` (`node_graph_engine.py`) resolves Concept vs Node via `MACRO_METADATA_RESOLVE_CYPHER` (`OPTIONAL MATCH` Concept/Node, `RETURN c, n`) then identities. It never traverses `DERIVED_FROM`.
- `get_metadata` in `context_retrieval.py` is a thin wrapper around `get_node_metadata`.
- Search hits collect `chunk_ids` / `doc_ids` from `OPTIONAL MATCH (node)-[:DERIVED_FROM]->(ch:Chunk)` but **not** `c.text`.
- Ingestion already writes `(n)-[:DERIVED_FROM]->(c:Chunk)` with `c.text`.

Did **not** bloat the public Fase 15 metadata payload. Added a targeted read used only by event-triage turn 0.

### What was added

- `FIND_EVENT_SOURCE_CHUNK_TEXT_CYPHER`: `MATCH (e:Node {id: $id})-[:DERIVED_FROM]->(c:Chunk) RETURN c.text AS text`.
- `_load_source_chunk_text`: joins non-empty texts with `\n\n`, slices to `EVENT_TRIAGE_SOURCE_TEXT_CAP` (4000). Exceptions / missing edges / blank chunks → `""`.
- `_load_readonly_context` appends `source_chunk_text=...` to the free turn-0 block (same observation as `get_relations`/`get_metadata`) only when text is present. `_user_prompt` already includes that block.
- FakeSession `_dispatch` returns linked chunk texts for tests.

## Phase 4 implementation notes

- `EventTriageStep` lives in `event_triage.py` next to `EventSlotItem` / `EventSlotProposal` (avoids a circular import with a new `app/models` file). Same shape as `AgentStep`: `action`, mandatory `reasoning`, `query` / `node_id` / `concept_id`, plus `slots` + `verified_no_change` when `action=propose`.
- `_seed_turn0` runs the former one-shot context (relations, metadata, `DERIVED_FROM` chunk text) and collects observed ids before the loop. `_triage_one_event` then loops `EVENT_TRIAGE_MAX_TURNS` times. A first-turn `propose` is one LLM call.
- `_filter_unobserved_slots` drops any slot whose `head`/`tail` is missing from the observed set and clears `verified_no_change` if anything was dropped (a mixed guess cannot confirm as «already correct»). `fonte` is not gated.
- Immediate-propose stubs that still return `EventSlotProposal` are accepted as `propose` (compat). Existing unit/corpus stubs now return `EventTriageStep(action=propose)` wrapping the same slots. Macrotask 8 tests `_prelink` slot endpoints onto the event so turn 0 observes those ids (the unlinked-entity corpus case is Phase 5).
